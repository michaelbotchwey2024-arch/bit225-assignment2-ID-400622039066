# BlueLib Catalogue

BlueLib Catalogue is a responsive online library catalogue developed for the BIT225 Advanced Web Technologies Assignment 2 at BlueCrest College.

The application allows students to browse available books, search for books by title, filter books by category, add new books, and borrow available books.

## Features

- Displays at least 6 books dynamically using JavaScript.
- Search books by title as the user types.
- Filter books by category.
- Add new books to the catalogue without reloading the page.
- Validates the book title, author, category, and number of copies.
- Prevents negative and decimal copy values.
- Borrow books and automatically reduce the available copies.
- Displays "Out of stock" when no copies are available.
- Disables the Borrow button when a book reaches 0 copies.
- Responsive layout for desktop, tablet, and mobile screens.
- Uses CSS Grid for displaying book cards.
- Includes hover effects on cards and buttons.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
